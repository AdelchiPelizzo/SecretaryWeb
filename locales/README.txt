SecretaryWeb localization files

en.json is the canonical key set based on the current English UI.
it/de/fr are translated for the marketing and core UI copy.
ru/zh/ar/ja contain translated core UI terms and preserve the complete key structure.
The remaining language files preserve the same complete key structure so the localization
code can support them immediately; their text should be professionally reviewed/translated
before enabling those languages for customers.

Arabic is marked direction=rtl. All other included languages are direction=ltr.
